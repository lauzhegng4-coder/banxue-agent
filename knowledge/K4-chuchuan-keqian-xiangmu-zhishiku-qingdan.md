# 一、做这件事的目的

调研不是为了写报告，是为了给知识库的判断层提供弹药。

- **用户骂什么 = 内容写什么**
- **竞品空白在哪 = 你的机会在哪**
- **用户决策路径 = 链路怎么设计**

判断层是三层知识库（信息层 / 故事层 / 判断层）中最有价值、最难被复制的部分。没有调研数据支撑的知识库，AI只能输出泛泛的大路货。

# 二、竞品调研 SOP（六步）

## 第一步：锁定竞品名单

收集范围分三类：

- 直接竞品：同品类同赛道
- 间接竞品：同人群不同品类
- 头部标杆：不论赛道，只看打法

## 第二步：平台大盘数据扫描

工具：巨量算数 + 爱搜 + 数据罗盘 + 抖音搜索下拉词

要跑的数据：

- 核心话题/关键词的曝光量、参与矩阵数、最高点赞（判断赛道热度天花板）
- 月均发布量趋势（判断赛道热度是涨还是跌）
- AI推荐词月覆盖量（月覆盖1000+的词优先深度布局）
- 搜索词下拉联想词（用户真实搜索意图）

## 第三步：逐个竞品拆解（四维度）

**流量结构**

**要看什么：**搜索占比/推荐占比/付费占比

*数据来源：数据罗盘/生意经*

**内容打法**

**要看什么：**主力内容类型（科普/测评/种草）

*数据来源：竞品主页/爱搜*

**链路设计**

**要看什么：**短视频→直播→商城→私域是否打通

*数据来源：抖音前台观察*

**账号矩阵**

**要看什么：**账号数/发布频率/KOL分层

*数据来源：巨量算数/爱搜*

## 第四步：差评聚类分析（用户洞察核心动作）

平台：竞品评论区 + 电商差评（1-3星）+ 小红书吐槽帖 + 抖音弹幕

收集量：500条以上，按主题分类。分类维度：

- 产品本身问题（效果 / 成分 / 口感 / 包装）
- 使用体验问题（不知道怎么用 / 剂量不清 / 场景困惑）
- 信任问题（怀疑真实性 / 对比不知选哪个）
- 服务问题（发货 / 售后 / 客服响应）

**每一类差评 = 一个内容选题方向。用户骂什么，你就写什么，这就是最精准的内容选题。**

## 第五步：用户决策路径还原

要搞清楚三个核心问题：

- 用户在哪个场景触发需求？
- 用户在哪个平台开始搜索？（抖音 / 小红书 / 百度 / 京东）
- 从看到内容到下单经过几次触达？（非即时需求产品需多次种草）

## 第六步：机会点总结 → 写入知识库判断层

格式：竞品做了什么 → 效果怎样 → 我们怎么做不同的 → 预期结果是什么

# 四、产出物标准（三样东西进知识库）

调研完成后，必须输出以下三个文档写入项目知识库的判断层：

**竞品空白地图**

**格式：**表格：竞品 / 空白词 / 空白内容类型 / 空白链路

*用途：直接指导选词工程和内容排期*

**用户痛点聚类表**

**格式：**三列：使用场景 / 核心痛点 / 用户原话

*用途：供脚本工程直接调用*

**判断规则清单**

格式：遇到[情况] → 策略是[做法] → 理由[数据]

*用途：写入知识库判断层，让AI代替你决策*

**这三样东西进了知识库，AI写的每一条内容才有判断力。没有这三样，AI只会输出泛泛科普，无法代你决策。**
