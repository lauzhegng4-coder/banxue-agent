# K6 · 楚川-课前准备-IP 深度访谈提纲（耗时较长）

> 来源：飞书 wiki（shengcaiyoushu01.feishu.cn/wiki/H5s1ww950iDDnHk6wjdcoeKhnYf）
> 抓取方式：WebFetch 部分抓取（截断于 Part 01 身份与起点 Q3）。完整版需飞书 API 全文抓取。
> 用途：搭建「IP 知识库」判断层前，用 2–4 小时深度访谈挖决策逻辑的提纲。

## 这份提纲的设计逻辑

普通访谈问「你做过什么」，这份提纲问「你在具体情境下为什么这么决定」。

- 判断力不在事件里，在决策背后的逻辑里。
- 全程追问「为什么」「当时数字是多少」「你当时有没有考虑过另一种做法」——这三个追问，能把一个普通答案变成判断库里最有价值的素材。
- 建议时长：正式访谈 2–4 小时（分两次也可以）。全程录音，事后转文字。
- 访谈者原则：不整理、不归纳、不帮对方说话——就是追问，让原话流出来。

## 访谈前：告诉被访者这段话（降低表演心）

> 「这次访谈没有标准答案，也不是为了让你显得厉害。我只想听你平时不会写进简历、不会发朋友圈的那部分——你真实踩过的坑、你做过的让自己后悔或骄傲的决定、你和别人不一样的地方。说错了可以重说，想到哪说到哪，我来整理。全程录音，你放心讲。」

设置原因：降低被访者的「表演心」，让他放松说真话，不是说官方版本的自己。

## Part 01 · 身份与起点（我是谁 · 从哪里来 · 为什么做这件事）

### 1.1 身份定位——用自己的话说

- **Q1** 如果让你向一个完全不认识你的人介绍自己，你会怎么说？不用想太久，就是你平时怎么介绍就怎么说。（听第一反应，不要提示。第一反应最接近真实自我认知。）
  - 追问 1：介绍完之后问——你觉得这个介绍最能代表你的是哪一句？
  - 追问 2：再问——有没有一句话是你想说但刚才没说出来的？
- **Q2** 你现在做的这件事，用一句话怎么概括？这句话你自己满意吗？（很多 IP 的「一句话定位」是别人帮他写的，和他真实感受有偏差——这里找原版。）
  - 追问 1：如果不满意，那他觉得哪里不对？什么才是他真正想表达的？
  - 追问 2：这句话是什么时候开始用的？用了多久？
- **Q3** 你是什么时候开始做现在这件事的？当时发生了什么，让你觉得「就是这个了」？（起点往往藏着 IP 最核心的叙事，要挖具体事件，不要「我一直对这个感兴趣」这种概括。）
