<title>楚川-课前准备 -IP 深度访谈提纲</title>

#  **这份提纲的设计逻辑**

普通访谈问「你做过什么」，这份提纲问「你在具体情境下为什么这么决定」。

判断力不在事件里，在决策背后的逻辑里。全程追问「为什么」「当时数字是多少」「你当时有没有考虑过另一种做法」——

这三个追问，能把一个普通答案变成判断库里最有价值的素材。

建议时长：正式访谈 2-4 小时（分两次也可以）。全程录音，事后转文字。

访谈者原则：不整理、不归纳、不帮对方说话——就是追问，让原话流出来。

#  **访谈前：告诉被访者这句话**

「这次访谈没有标准答案，也不是为了让你显得厉害。

我只想听你平时不会写进简历、不会发朋友圈的那部分——

你真实踩过的坑、你做过的让自己后悔或骄傲的决定、你和别人不一样的地方。

说错了可以重说，想到哪说到哪，我来整理。全程录音，你放心讲。」

*设置这段开场白的原因：降低被访者的「表演心」，让他放松说真话，不是说官方版本的自己。*

# Part 01  ·  **身份与起点**

*我是谁 · 从哪里来 · 为什么做这件事*

##   **1.1  身份定位——用自己的话说**

**Q1**

**如果让你向一个完全不认识你的人介绍自己，你会怎么说？不用想太久，就是你平时怎么介绍就怎么说。**

 *听第一反应，不要提示。第一反应最接近他真实的自我认知。*

**追 问**

1. 他介绍完之后问：你觉得这个介绍最能代表你的是哪一句？

2. 再问：有没有一句话是你想说但刚才没说出来的？

**Q2**

**你现在做的这件事，用一句话怎么概括？这句话你自己满意吗？**

 *很多 IP 的「一句话定位」是别人帮他写的，和他真实感受有偏差——这里找原版。*

**追 问**

1. 如果不满意，那他觉得哪里不对？什么才是他真正想表达的？

2. 这句话是什么时候开始用的？用了多久？

##   **1.2  起点与入场——为什么是你来做这件事**

**Q3**

**你是什么时候开始做现在这件事的？当时发生了什么，让你觉得「就是这个了」？**

 *起点往往藏着 IP 最核心的叙事，要挖具体事件，不要「我一直对这个感兴趣」这种概括。*

**追 问**

1. 当时有没有一个具体的「触发事件」——某件事、某个人、某句话？

2. 如果没有那件事，你现在还会做这个吗？

3. 你那时候身边有人反对或不理解吗？他们怎么说的，你怎么想的？

**Q4**

**你做过哪些「上一份工作」或「上一段经历」？这些经历里，什么东西是你带到现在来的？**

 *过往经历是 IP 背书和差异化的核心来源，要具体到公司/项目/时间节点。*

**追 问**

1. 有没有某段经历让你到今天还受益？具体是什么？

2. 有没有某段经历你觉得是弯路，但现在回头看有什么价值？

# Part 02  ·  **价值观与边界**

*我相信什么 · 我不做什么 · 我的红线在哪*

##   **2.1  核心信念——你真正相信的事**

**Q5**

**做这件事这么久，你最坚持的一个判断是什么？这个判断和行业里大多数人不一样。**

 *这是「反常识观点」的核心来源，也是 IP 内容传播力最强的部分。一定要追到具体。*

**追 问**

1. 这个判断是怎么形成的？有没有一件具体的事让你确信「就是这样」？

2. 有没有人公开反驳过你？你怎么看待那些反驳？

3. 你有没有因为这个判断吃过亏？

**Q6**

**有没有行业里的「主流做法」你根本不认同？大家都这么做，但你觉得这是错的？**

 *「我不认同 X，原因是 Y」是最有传播力的内容句式——找3个这样的判断。*

**追 问**

1. 你自己以前有没有也这么做过？后来为什么改变？

2. 如果让你写一篇文章反驳这个主流做法，你的核心论点是什么？

**Q7**

**你觉得自己做这件事，和大多数同行最本质的区别是什么？不是「我更用心」——是具体的、能量化或能举例的差异。**

 *差异化是 IP 内容的护城河，要逼出具体的，不接受模糊答案。*

**追 问**

1. 你有没有一个案例或对比，能直接说明这个差异？

2. 这个差异是天生的，还是后来刻意建立的？

##   **2.2  边界与红线——你不做什么**

**Q8**

**有没有某种类型的客户或合作，你现在无论如何不会接？原因是什么？**

 *「不做什么」比「做什么」更能定义 IP 的立场，也是判断层最有价值的素材。*

**追 问**

1. 你以前接过这样的合作吗？结果怎么样？

2. 如果对方出的价格很高，你会不会考虑？这个边界是绝对的还是有弹性的？

**Q9**

**有没有某些话，你在内容里绝对不会说？哪些立场，你不会公开表达？**

 *这是「禁用内容」和「人设红线」——AI 生成内容时必须知道这些边界。*

**追 问**

1. 这些边界是怎么确定的？有没有因为说了不该说的话吃过亏？

2. 如果有人问你这些话题，你通常怎么应对？

**Q10**

**你最在意别人对你的什么误解？有没有一个标签是外界给你贴的，但你觉得完全不准确？**

 *误解往往暴露 IP 的「真实自我认知」与「外部形象」之间的落差——这是内容矫正的方向。*

**追 问**

1. 这个误解是怎么产生的？你有没有主动做过什么来纠正它？

2. 如果你只能做一件事来消除这个误解，你会做什么？

# Part 03  ·  **声音与语言质感**

*你怎么说话 · 你的句式 · 你的金句*

##   **3.1  语言习惯——怎么说才像你**

**Q11**

**你有哪些说话的习惯？朋友有没有模仿过你？你自己有没有注意到某些词你特别爱说？**

 *高频词和口头禅是语言风格层最难自我察觉的部分，让他自己说，再追问。*

**追 问**

1. 能不能现场说一段话——就像你在和客户解释某件事一样？

2. 你平时解释一个复杂概念，最常用的比喻是什么？举个例子。

**Q12**

**有哪些说法你特别不喜欢用？听到别人这么说你会觉得不舒服——哪怕意思差不多？**

 *禁用词库是语言风格层最容易被忽略的部分，但 AI 生成时最需要。*

**追 问**

1. 比如「赋能」「链接」「生态」这类词，你怎么看？有没有你自己的替代说法？

2. 你觉得哪种表达方式「太 AI 腔」，让你看到就想删？

##   **3.2  金句挖掘——只有你能说出来的话**

**Q13**

**你说过哪句话，被别人截图、引用或者转发过？你还记得是什么场合说的吗？**

 *被转发过的话是天然金句，要尽量多收集，让他一条一条说原话。*

**追 问**

1. 这句话你是怎么想到的？当时是脱口而出还是想了很久？

2. 这句话你现在还认同吗？还是已经有了新的判断？

**Q14**

**如果用一句话概括你做这件事的核心方法论，你会怎么说？**

 *这是「一句话方法论」——IP 内容最高频调用的核心句式。*

**追 问**

1. 这句话是你自己想的，还是从哪里学来的？

2. 有没有一个反例能说明「不按这个来会怎样」？

**Q15**

**如果你要出一本书，书名是什么？副标题是什么？**

 *书名逼迫他提炼最核心的判断，往往是意想不到的金句来源。*

**追 问**

1. 这个书名是你脑子里第一个冒出来的，还是你最想说的那个方向？

2. 这本书的第一章你会写什么？

# Part 04  ·  **判断力与决策逻辑**

*遇到 X → 我的判断是什么（最贵的部分）*

 **为什么这一部分是整个访谈最重要的**

判断逻辑层是 IP 知识库里 AI 最难自己生成的部分。

AI 可以从网上学到「客户嫌贵要讲价值」，但它不知道「你遇到客户嫌贵时，第一句话是什么，第二步做什么，什么情况下你会主动放弃这个客户」。

格式：「遇到[具体情境] → 我的判断是[具体决策]，因为[逻辑]」

目标：挖出 10 条以上，越具体越有价值。

##   **4.1  商业决策——如何判断要不要做一件事**

**Q16**

**你接到一个新合作邀请，你判断要不要接的标准是什么？你通常看哪几个维度？**

 *商业决策判断是判断层的核心场景，要追到具体标准，不是「看感觉」。*

**追 问**

1. 有没有一次你按这个标准拒绝了，但后来觉得拒错了？

2. 有没有一次你破例接了，结果怎样？

3. 如果对方给的钱是平时的三倍，你的判断标准会变吗？

**Q17**

**你做过的最贵的一个决定是什么？当时是怎么判断的，现在回头看？**

 *「最贵的决定」不一定是花钱最多的，可以是代价最大的——时间、机会、关系。*

**追 问**

1. 那个决定是你一个人做的还是和谁商量的？

2. 如果当时有一个人告诉你另一种做法，你会改变判断吗？

3. 这件事让你之后做类似决定时，加了什么「过滤条件」？

**Q18**

**你是怎么判断一个机会是真机会还是坑的？有没有某个「感觉」或「信号」你会特别在意？**

 *这是「机会识别判断力」——高价值 IP 的核心竞争力之一。*

**追 问**

1. 有没有一次你的「感觉」救了你，是什么感觉？

2. 有没有一次你压制了那个感觉，结果踩坑了？

##   **4.2  内容与 IP 决策——怎么判断做什么内容**

**Q19**

**你怎么判断一个选题值不值得做？不是靠数据——是你看到一个话题，脑子里第一反应是什么？**

 *内容判断力是 IP 最独特的部分，要挖他自己的直觉判断逻辑。*

**追 问**

1. 你判断一个选题好不好，最快的方式是什么？

2. 有没有某类选题，数据很好但你不想做？为什么？

3. 有没有某类选题，数据一般但你觉得必须做？为什么？

**Q20**

**有没有一条内容，你发出去之前就知道它会爆？你是怎么判断的？**

 *「爆款预判力」是判断层里最有说服力的能力证明。*

**追 问**

1. 能描述一下当时的感觉吗？是什么让你有这种判断？

2. 这个判断准确率大概多少？你有没有统计过？

**Q21**

**遇到内容数据很差，你的第一反应是什么？你怎么区分「是内容问题」还是「是平台问题」？**

 *这是「坏结果归因判断」——AI 必须知道他的复盘逻辑。*

**追 问**

1. 你复盘一条内容通常看哪几个指标？顺序是什么？

2. 有没有一次你误判了原因，后来才发现？

##   **4.3  人际与客户判断——如何应对具体的人**

**Q22**

**遇到客户质疑你的专业性，你怎么回应？是解释、反问、还是直接放弃？**

 *这是最高频的实战判断场景，要问到具体的话术逻辑。*

**追 问**

1. 你第一句话通常说什么？为什么是这句？

2. 有没有一种质疑方式让你直接选择放弃这个客户？

3. 你判断一个客户「值得花时间解释」的标准是什么？

**Q23**

**遇到你认为对方期望值太高但你没有能力完全满足，你怎么处理？**

 *这是「期望管理判断力」——高级 IP 的核心能力，很多人在这里翻车。*

**追 问**

1. 你会主动说出来还是先接再说？为什么？

2. 有没有一次你没说，后来出了什么问题？

3. 你一般用什么方式管理这类客户的预期？

**Q24**

**遇到同行公开批评你或者复制你的做法，你的判断是什么？**

 *同行竞争判断是判断层里最容易被回避的话题，要温和但坚定地追。*

**追 问**

1. 你会公开回应吗？什么情况下会，什么情况下不会？

2. 有没有一次你判断「这个值得回应」，结果怎样？

3. 你怎么看待模仿和竞争——是激励还是消耗？

# Part 05  ·  **人生故事库**

*转折 · 高光 · 失败 · 最真实的那些*

*这一部分是知识库「温度」的来源。AI 写出来有人味，靠的就是这些真实发生过的、有细节的事。追问重点：时间节点、具体数字、当时的情绪、事后的复盘。*

##   **5.1  转折点——改变了一切的那件事**

**Q25**

**你人生或职业里，有没有一个「转折点」？如果没有它，你今天会完全不同？**

 *转折故事是 IP 最核心的叙事骨架，要有具体时间、地点、发生了什么。*

**追 问**

1. 那个时刻你是什么感受？有没有一句话是你当时对自己说的？

2. 那之前你是什么状态？那之后第一件事是什么？

3. 现在你怎么看那个转折——是命运，还是自己选的？

**Q26**

**有没有一次你主动放弃了一个「看起来很好」的机会？当时是什么判断？**

 *主动放弃的故事比「逆境反转」更能体现判断力——这类故事很少被问到。*

**追 问**

1. 放弃之后有没有后悔过？现在怎么看那个决定？

2. 如果没有放弃，你觉得现在会是什么状态？

##   **5.2  高光时刻——你最骄傲的那次**

**Q27**

**做到现在，让你最骄傲的一件事是什么？不是结果，是过程——你当时做了什么让你现在回想起来还很骄傲？**

 *「骄傲的过程」比「骄傲的结果」更有内容价值——追过程，不是数字。*

**追 问**

1. 那件事里，有没有一个时刻你觉得「我做到了」？是什么时刻？

2. 那件事里，你做了一个别人不会做的决定——是什么？

3. 有没有一个人因为那件事对你说过一句话，让你记到现在？

**Q28**

**你帮过的客户或学员里，有没有一个案例让你到现在还有成就感？发生了什么，结果是什么？**

 *客户成功故事是 IP 内容转化力最强的素材，要有具体数字和前后对比。*

**追 问**

1. 那个案例里，你做的最关键的一件事是什么？

2. 如果那个客户现在来推荐你，他会说什么？

3. 这个案例有没有让你更新或改变了什么判断？

##   **5.3  失败与复盘——你踩过的最深的坑**

**Q29**

**你做这件事以来，踩过的最惨的坑是什么？当时是什么情况，损失了什么，你怎么复盘的？**

 *失败故事是判断力来源，也是最有「人味」的内容素材。不要放过细节。*

**追 问**

1. 那次失败，你第一反应是什么？有没有一段时间你状态很差？

2. 你是怎么走出来的？有没有一个具体的动作或决定是转折点？

3. 这件事让你之后做事改变了什么？你加了哪条「规则」？

**Q30**

**有没有一次你做了一件事，当时觉得对，但后来觉得是这件事里最错的决定？**

 *「当时对，后来错」的判断是最有深度的复盘素材，也是最难被问出来的。*

**追 问**

1. 你是什么时候发现这个判断错了的？是什么触发了这个认识？

2. 如果让你再做一次，你会做什么不同的选择？

3. 这件事有没有影响你对某个人或某类判断的信任？

**Q31**

**你最后悔的一件事是什么？（可以不和职业有关）**

 *「最后悔」是比「失败」更私人、更有温度的问题——回答这个问题的 IP 内容转化率极高。这是可选题，被访者可以不回答。*

**追 问**

1. 如果当时做了不同的选择，你觉得今天会不会更好？

2. 这件事有没有让你在某些地方变得不一样了？

# Part 06  ·  **方法论与行业洞察**

*你的核心框架 · 你对行业的判断*

##   **6.1  核心方法论——你是怎么做到的**

**Q32**

**你做这件事的核心方法论是什么？如果只能教别人一件事，你教什么？**

 *核心方法论是 IP 最有传播价值的内容，要逼他说出具体步骤，不是理念。*

**追 问**

1. 这个方法论你是怎么摸索出来的？经过了多少次迭代？

2. 这个方法论有没有失效的情况？什么条件下不适用？

3. 你现在还在用的时候，哪个步骤是最多人做不对的？

**Q33**

**你做这件事的时候，有没有某个「反直觉」的操作——大多数人会做 A，但你做 B？**

 *反直觉操作是方法论中传播力最强的部分，也是 IP 最难被复制的竞争力。*

**追 问**

1. 你是什么时候发现这个反直觉方法的？怎么验证它有效？

2. 有没有人按你说的做了，结果比你预期还好？

##   **6.2  行业洞察——你怎么看这个行业的未来**

**Q34**

**你觉得你所在的行业，未来 2-3 年会发生什么重要变化？大多数人还没意识到的那种。**

 *行业预判是 IP「权威感」最快的建立方式，也是最能引发转发的内容类型。*

**追 问**

1. 这个判断是基于什么信号？你从哪里看到这个趋势？

2. 如果这个变化真的发生，现在的哪类人会受益最大？哪类人会最快被淘汰？

3. 你自己为这个变化做了什么准备？

**Q35**

**你觉得现在行业里哪个「显学」是泡沫——大家都在追，但你觉得 2 年后会证明是浪费？**

 *「行业泡沫判断」是高转发内容的黄金题材，但也是高风险的——要看他愿不愿意说。*

**追 问**

1. 你自己有没有追过这个泡沫？结果怎样？

2. 你是什么时候确定「这是泡沫」的？有没有一个具体时刻？

# Part 07  ·  **私域话术与应对逻辑**

*遇到真实问题时你怎么说*

*这一部分直接决定 AI 生成的私域内容、成交话术、异议处理能不能「说的像你」。要用原话，不是总结。*

**Q36**

**客户说「你们比 XX 贵」，你第一句话是什么？后面怎么接？**

 *用原话。不是「我会解释价值」，是「我当时说的是……」*

**追 问**

1. 这套话术是怎么摸索出来的？试过哪些版本？

2. 有没有一次这套话术没用？当时发生了什么？

3. 你怎么判断一个客户是「真的觉得贵」还是「习惯性砍价」？判断不同，话术不同吗？

**Q37**

**客户说「我再考虑一下」，你怎么处理？你会追还是等？**

 *跟进话术是成交卡点里最核心的判断力，追问他的具体操作逻辑。*

**追 问**

1. 你一般等多久再跟进？第一次跟进你说什么？

2. 有没有一次因为跟进方式不对，客户跑了？当时哪里错了？

3. 你怎么判断这个客户「值得多次跟进」还是「不要浪费时间」？

**Q38**

**你最常被客户问到的 3 个问题是什么？你的标准回答各是什么？**

 *直接让他说原话，每个问题配一套完整的回答，这就是 FAQ 库的原材料。*

**追 问**

1. 这个标准回答是你想了很久的，还是哪次和客户聊完之后形成的？

2. 有没有某个问题，你一直觉得自己回答得不好？

**Q39**

**有没有客户提出过一个让你意外的问题——你当时没想到，但后来你觉得这个问题问得很准？**

 *「意外的好问题」往往揭示了客户的真实需求和 IP 的盲区。*

**追 问**

1. 那个问题是什么？你当时怎么回答的？

2. 这个问题有没有改变你之后的某些说法或做法？

# Part 08  ·  **关系与圈子**

*你受谁影响 · 你如何影响别人*

**Q40**

**你职业路上对你影响最大的一个人是谁？他给了你什么——不是资源，是判断或认知？**

 *重要影响者往往是 IP 价值观和方法论的来源，这里会挖出很多「从哪里来的」的答案。*

**追 问**

1. 他说过一句让你到今天还记着的话，是什么？

2. 你现在做某个决定的时候，有没有会想「他会怎么看这件事」？

**Q41**

**你影响过的人里，有没有一个让你觉得「这就是我做这件事的意义」？发生了什么？**

 *「影响他人」的具体故事是 IP 内容中转化率最高的情感素材。*

**追 问**

1. 那个人现在怎样了？你们还有联系吗？

2. 那件事发生之后，你对自己的定位有没有变化？

**Q42**

**如果让你描述你的「理想客户」或「理想学员」——不是画像标签，是你真的最喜欢和什么样的人合作？**

 *「真实偏好」比「理性画像」更能帮 AI 筛选内容受众，也更有温度。*

**追 问**

1. 你和这类人合作时，有什么不一样的感受？

2. 有没有一个人是你合作过的最让你满意的，他是什么样的人？

# Part 09  ·  **未来与自我认知**

*你想成为什么 · 你现在最在意什么*

**Q43**

**3 年后你希望自己处于什么状态？不是「更成功」——是具体的，一天是什么样的？**

 *「具体的理想状态」比「宏大目标」更能帮 AI 在内容中对齐 IP 的方向感。*

**追 问**

1. 这个状态和你现在的差距，最大的一个是什么？

2. 你现在每天做的事，有多少是在朝这个方向走的？

**Q44**

**你现在最焦虑的是什么？不是工作上的，是你作为一个人，最担心的事。**

 *焦虑是最真实的「当下状态」，也是 IP 内容里最能引发共鸣的素材来源。*

**追 问**

1. 这个焦虑是最近才有的，还是一直都在？

2. 你有没有一个应对这个焦虑的方式？

**Q45**

**如果你现在的一切重来，你最想改变的一件事是什么？**

 *这是整个访谈最后的「收底」问题，用来挖最深的自我认知。可以给被访者一点时间想。*

**追 问**

1. 改变了那件事，你觉得会有什么不同？

2. 那件事有没有让你做了什么你原本不会做的事——这件事反而是好的？

# **访谈结束：验收清单**

 **达标才能进入 Codex 整理环节**

录音文字稿总字数 > 2 万字（理想目标 3-5 万字）

判断逻辑层（Part 4）：有具体情境+具体判断的条目 ≥ 10 条

故事库（Part 5）：含时间/数字/细节的真实事件 ≥ 3 个

金句库（Part 3）：被访者原话，未经整理 ≥ 8 条

方法论（Part 6）：核心步骤说清楚了，不是停在理念层

话术（Part 7）：每个场景都有原话，不是「我会解释价值」这种概括

**❌ 不够用的答案（进不了判断层）**

**✅ 有用的答案（可以入库）**

「遇到客户嫌贵，我会解释价值」

「我先问他在哪里看到的，再打开复购率截图说：能持续买第二次才是真省钱」

「我最大的失败是没有坚持下去」

「2021年，我花了140万做了一个直播间，三个月亏完，当时每天睡三个小时……」

「我和同行的区别是我更用心」

「我做的每个方案第一步是去看竞品差评，他们不做这个——我找到的机会全在那里」

「我有自己的方法论」

「我的方法是：先看差评，找Top3痛点，再倒推关键词，再出脚本——这个顺序不能反」

「我觉得内容很重要」

「我有一条规则：一条内容如果发出去前我自己不会发朋友圈，就不发」
