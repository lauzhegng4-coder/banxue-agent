## 二、结论级骨架（每份 3–5 行）

### 楚川板块

**K1 · 0725 Day1：知识库是 AI 时代的地基**
- 五层积木：知识库 → 选词 → 脚本 → 素材 → 流水线合成分发；数据复盘写回知识库形成闭环。
- 知识库三层：信息层 / 故事层 / 判断层。工具会迭代，判断力护城河可迁移。
- 判断力四类来源：差评/用户洞察、竞品分析、自身竞争力（可量化）、失败挫折经验。
- 差评手把手：四平台各 20–30 条 → 凑 100+ 去重 → 原话复制给 GPT 聚类 → 写进知识库。
- IP 库案例（谢晶 45万→240万）/ 项目库案例（升学教育 60天佣金32万）。

**K2 · 0726 Day2：给「1」后面加零**
- 选词是知识库的延伸（SEO 是索引）；关键词五层：品类/场景/痛点/人群/长尾。
- 脚本三段式：1–5s 钩子 / 5–30s 卖点拆解 / 30–60s 购买理由+CTA；四类钩子。
- 素材两类：真人实拍（高信任）vs AI 生成（须垂直微调+人工终审）；流水线三原则：不全自动、不一键成片、人买单。
- 人×AI 分工：AI 做 80%，人做 20%（真实性/终审/拍板）。
- Agent 串联 = 跑通的 SOP 串起来；三步起手：第1月建地基→第2月跑模板→第3月验 ROI。

**K3 · 大课讲义整合版**：与 K1/K2 同源的连贯讲义，含全部实操步骤、表格、案例数据。优先查此份。

**K4 · 项目知识库信息收集清单**：六步竞品调研 SOP（锁名单→大盘扫描→四维度拆解→差评聚类 500 条→决策路径还原→机会点写入判断层）；五类资料清单（A 平台数据/B 用户原声/C 竞品内容库/D 人群洞察/E 行业基础）；产出物三样进知识库：竞品空白地图、用户痛点聚类表、判断规则清单。

**K5 · IP 轻度访谈提纲**：六部分 25 问（语言风格/金句/观点体系/人生故事/私域话术/判断逻辑）；判断逻辑层格式「遇到[情境]→我的判断」，挖 8–10 条；验收：>1 万字、判断 ≥8 条、故事 ≥2 个、金句 ≥5 条原话。

**K6 · IP 深度访谈提纲**：九 Part 45 问（身份起点/价值观边界/声音语言质感/判断力决策逻辑/人生故事库/方法论行业洞察/私域话术/关系圈子/未来自我认知）；Part 04 判断逻辑挖 ≥10 条含情境+决策+逻辑；文末「❌ 不够用 vs ✅ 有用」答案对照表；验收：>2 万字、判断 ≥10 条、故事 ≥3 个、金句 ≥8 条。

### 叁斤板块

**K7 · 0725 大课讲义《从知识库到 Skill：搭建你的第一个内容 Agent》（总纲）**
- 课前三件套：3 个 skill（采访机器人/录音处理/朋友圈文案）+ 六大知识库骨架。
- 核心路径：知识库（上下文）→ Skill（标准流程）→ 内容 Agent；模型是公共的，知识库让它认识你。
- 六大库：老板说明书 / 产品库 / 客户需求库 / 素材案例库 / 方法论库 / 内容生产库——AI 写内容从这取料。
- 课程暗线：结构化表达——说清客户是谁、问题是什么、任务怎么完成、什么算合格。

**K8 · 0725 PPT 73 页**：K7 的现场版，逐页文字 + 备注，查具体页码细节时用。

**K9 · AI 内容获客系统线下课讲义**：两天十模块一条连续路径：需求证据→内容判断→AI 协作→知识库→工作流→内容生产→工作台→流量承接；四个检查点是逐半天的交付清单；「结课后只做一件事」。

**K10 · 富贵老师：人群洞察与内容底层逻辑**
- **先有人群，后有需求；需求是被创造出来的。**「同一个标签之下藏了 1000 个不同的人。」
- 流量质量：精准小流量优于泛大流量；有讲故事能力才有定价权，有想象空间才有利润。
- 知识平权时代，稀缺的不是信息，是洞察。
- 四步核心模型：看到人群→了解他→找到他现在的问题→给他制造想象。
- 人群八维拆解：自然人口/社会/消费模式/行为场景/生活方式/当下情绪/长期情感需求/价值观。

**K11 · AI 个人知识库搭建**
- 知识库的本质：**AI 的上下文，在电脑里的映射就是个文件夹**。「没有那么的玄，很朴实无华。」
- Skill 的本质：一套标准执行流程；模型和 Skill 要跑好，背后都需要专属知识库。
- 别人的 Skill 用不顺手 = 缺你自己的知识库上下文；自己的 Skill 也要在本地跑一遍适配。
- Obsidian 只是给人看的界面，数据本体是文件夹。

**K12 · AI 业务工作流拆解**
- 「AI 时代最值钱的能力之一：把你自己的任务拆解清楚。」
- 第一性原理拆解：先明确本质产出 → 倒推必要环节 → 每步问「能不能单独让 AI 完成」→ 拆到能单独交付为止。
- 与「照搬自己做法」的区别：你的方法可能本来就在绕远路。

**K13 · AI 工作台搭建与应用**
- 工作台 = 采集器 + 盯盘器 + 展示窗口；每个界面对应一个高频、具体、反复的工作场景，否则是空架子。
- 工作台只是前端展示层，后端执行靠 Claude Code/Codex + 本地知识库。
- 自用版（本地）vs 员工版（云端 API）；与数字员工平级，可同步搭建。

**K14 · 新年课：AI 内容获客（3 小时最全版）**
- 找对标工作流：关键词 → AI 自动找对标笔记/账号/下拉词 → 采评论区 → 深挖账号近 20-40 天笔记 → Claude 分析出报告。
- 监控雷达：定时巡查关键词/博主/话题的新增与爆款（点赞>1000 标记），每天出动态报告。
- 两整天结构：D1 上午获客方法论 + 下午搭知识库；D2 上午梳理业务 + 下午搭工作台。

### 包子板块

**K15 · 大课讲义《成为 AI 的伯乐，成为 AI Native》（总纲）**
- 核心命题：**用了 AI ≠ AI Native**。很多人用旧工作方式指挥 AI，AI 越快手里的半成品越多，反而更累。
- 「世有伯乐，然后有千里马」：不是 AI 没有千里马的能力，是我们拿它当拉磨的马。四根缰绳：旧流程 / 工具思维 / 不放心（窄上下文）/ 人还想当总调度。
- AI Native 定义：不是让 AI 帮我完成旧工作，而是重新设计工作，让 AI 原生长在生产流程里。标签五件套：知识库 / 上下文 / 工作流 / 杠杆复利 / 人机协作。
- Day1 实操线：AI 重塑视频生产——项目文件夹（不是聊天框）→ GitHub 版本管理 → Codex 看懂资料 → 明确目标 → 出片 → 做视频工作台 → 分工提议 → 工程化改造；加餐 heygen 数字人 + minimax 声音克隆。
- Day2 蓝海线：AI 时代新品类 = 过去成本太高无法生产的个性化交付物，第一次被低成本做出来。六步：搭办公室 → AI 理解工作现状 → 讲清需求（10 分钟语音讲能力/约束/生活选择）→ 推导「AI 时代才成立」的产品假设 → mini demo 最小闭环 → 正式研发（Human-in-the-loop / Guardrails / Evals 三概念落地）。
