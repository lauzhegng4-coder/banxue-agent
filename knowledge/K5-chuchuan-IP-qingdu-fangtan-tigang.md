# K5 · 楚川-课前准备-IP 轻度访谈提纲（耗时较短）

> 来源：飞书 wiki（shengcaiyoushu01.feishu.cn/wiki/JJKfwls5LiJ0wCkE3Vvcsilhnfh）
> 抓取方式：WebFetch 部分抓取（截断于「第二部分 金句库」之后）。完整版需飞书 API 全文抓取。
> 用途：搭建「IP 知识库」前，用 1–2 小时访谈收集原始素材的提纲。

## 使用说明

- 目标：通过 1–2 小时访谈，获取至少 3 万字原始素材，用于搭建 IP 知识库六层框架。
- 格式：全程录音（不要手动记录），事后转文字再丢给 Codex 整理。
- 最重要原则：访谈时不要整理，就是说话。原话才是知识库最有价值的部分——整理过的话已失去语气。
- 追问原则：每当被访者说了一个观点，追问「你能给我举个具体的例子吗？」「当时数字大概是多少？」「那你当时是怎么想的？」——细节和数字是故事库的燃料。

## 第一部分：语言风格层

目标：让 AI 学会你说话的方式——哪些词是你的口头禅，哪些表达你绝对不用。

- **Q1** 你有哪些经常说的词或短语？别人说你总是爱说什么？（让被访者自己说，不要给选项。可问：你朋友有没有模仿过你说话的方式？）
- **Q2** 你最常用的表达方式是什么？举例说一段你平时讲课/发朋友圈时最典型的话。（最好直接让他说一段话录下来，就是原始语气素材）
- **Q3** 有哪些说法你绝对不会用？听到别人这么说你会觉得很别扭？（这是「禁用词库」的原材料，很重要，很多人忽略）
- **Q4** 你在解释一个道理时，最爱用什么样的比喻或类比？（比喻是语言风格最有辨识度的部分，让他举 2–3 个例子）

## 第二部分：金句库

目标：收集至少 8–10 条「只有你能说出来」的原话，保留原文，不改写。

- **Q5** 你说过哪句话，被学员/客户截图发朋友圈或者反复引用？（天然金句，让他一条条说，尽量用原话）
- **Q6** 你对自己所在行业有什么「反常识」的判断？大多数人怎么想，你怎么想？（反常识判断是金句高浓度来源，也是观点体系核心）
- **Q7** 做这件事这么多年，你最想对刚入行的人说一句什么话？（浓缩多年判断的精华句，让他直接说，别想太久）
