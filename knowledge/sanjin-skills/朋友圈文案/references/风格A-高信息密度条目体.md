# 风格 A·高信息密度条目体

## 一句话定义

把多条独立观点并列输出，一条一段，数字 emoji 分隔，让读者快速过知识。

## 适用场景

- 线下交流复盘（最典型场景，参考"参加航海家AI交流会，整理10条普通人AI变现与内容实操干货"）
- 课程学习心得
- 读书笔记
- 长录音整理（线下分享/对话）
- 经验沉淀类（"关于XX我有 N 条最关键认知"）

## 核心特征

**信息密度大于观点深度**——读者一次性获得很多信息点，不深挖任何一个。

每条信息点独立成立，不依赖前后文。读者可以从任意一条开始读。

## 长度

- 800-1500 字（长文案）
- 10-12 条最佳，少于 6 条信息密度不够，多于 15 条疲劳

## 结构模板

```
【开头】
昨天/最近/今天[做了什么事]，信息量很大，我把核心收获整理一下。
↓
1️⃣ [观点1]
[简短论证或例子，1-3句话]

2️⃣ [观点2]
[简短论证或例子，1-3句话]

...

🔟 [观点10]
[简短论证或例子]

【可选收尾】
一两句金句或反问，或直接以最后一条收尾。
```

## 开头模式

固定句式："X 了 [场景]，整理 N 条 [主题]"

- "昨天参加了航海家见面会的 AI 交流，信息量很大，我把核心收获整理一下。"（参考航海家10条）
- "关于虚拟电商，我有10条最关键的认知。"（#46）
- "新手从0到1做虚拟产品，最快出成绩的8大核心运营心法"（#45）
- "最近的一些关于 AI 观察："（#38）
- "发现小红书几个很诡异的「真相」"（#07）
- "知道做盗版也一定会死，为什么会还要做？线下交流复盘"（#39）

## 每条结构

**两种格式可选：**

**格式 1·小标题式**（适合每条有独立主题词的场景）
```
1️⃣ 选品认知

做虚拟电商，选品是唯一重要的事。除了选品之外，其他全部都不重要。
```

**格式 2·直接陈述式**（适合每条本身就是一句完整观点）
```
1️⃣ 普通人用 AI 变现，不应该追新工具，而是把自己的经验、判断、案例整理成可以被 AI 调用的系统。
对内可以帮你工作，对外变成产品卖出去。
```

## 句式特征

- **每条用一句话核心论断打头**，后面跟 1-2 句解释或例子，绝对不超过 3 句
- 不展开论证，不举多个例子，**点到为止**
- **第一句必须直接给观点**，禁止"接下来我们聊聊…""下面来看一下…"这种铺垫

## 结尾模式

3 种处理方式：

1. **最后一条直接收尾**（最常见）——没有总结，最后一条说完就结束
2. **加一句金句**——"你不需要做全国第一，只需要找到一个足够具体、有人愿意付费、现有体验还不够好的小场景。"（航海家10条）
3. **加一句感悟**——"小不代表没价值，人群基数够大，小需求也是一门生意。"

**禁止**：写"以上就是10点分享""综上所述"等总结句。

## 写作要点

1. **观点必须独立**：第3条删了不影响第7条。如果存在递进关系，那应该走方法论拆解体（风格 E）
2. **数量预设**：开头就说清楚有几条，让读者有预期
3. **节奏控制**：每条字数差距不要太大，否则读起来卡顿
4. **emoji 一致**：要么全用 1️⃣2️⃣3️⃣，要么全用 1. 2. 3.，不混用
5. **不滥用粗体**：每条第一句话不需要加粗，编号本身已经是视觉锚点

## 与其他风格的区别

- **vs 风格 E 方法论拆解**：A 是并列条目，E 是步骤递进。"10 条认知"是 A，"4 步搞定 XX"是 E
- **vs 风格 D 碎碎念**：A 信息量大、客观陈述，D 个人感受强、主观抒情
- **vs 风格 B 观点驳论**：A 是分发观点不预设立场，B 是聚焦一个反常识论断打到底

## 调用方式

写作前读取本文件 → 套用结构模板 → 控制每条字数和句式 → 检查是否每条独立成立。
