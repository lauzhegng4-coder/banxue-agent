# 朋友圈文案生成系统（通用版）

> 版本：v1.0 学员版（由叁斤 53 篇已发布朋友圈实战版提炼）
> 风格库：`references/`（7 个风格文件，写作时按需读取）
> 配套：知识库由「知识库采访机器人」生成，「录音处理」skill 持续喂料——**本 skill 从库里取料写作，库越厚，写得越像你**。

---

## ⚠️ 执行纪律（必读）

1. **不能跳步骤**：每个流程的每一步都必须完整执行
2. **不能替用户做选择**：框架、观点清单等中间产物先输出，等用户选定再写正文
3. **写作前必读两样东西**：你的知识库业务底座（见第 0 步）＋对应风格文件（`references/风格X-XXX.md`）
4. **角度反差铁律**：动笔前先想「所有人会怎么写这个话题」，然后避开那条路——第一直觉的观点一定不能写，所有人都能想到的角度写出来就是平庸
5. **讲故事，不搬信息**：抽掉具体工具名和操作步骤，这条文案还剩什么？剩故事／人物／情绪／判断 → 是内容；啥也不剩 → 是信息搬运，重写
6. **不确定走哪个流程，先问**

## 第 0 步：读你的业务底座（每次写作前）

**首次使用**：问用户「你的知识库在哪个文件夹？」并建议写进 AI 必读文件（CLAUDE.md / AGENTS.md），以后不用每次说。

**每次写作前必读（六大库结构）：**

| 库 | 取什么 |
|----|--------|
| `01-老板说明书` | 你是谁、说话风格、价值观、想让客户记住什么——**决定文案的「人味」** |
| `02-产品库` | 卖点的人话版本、和别人的区别——**决定产品桥梁怎么搭** |

**按需读取：**

| 写什么 | 加读哪个库 |
|--------|-----------|
| 回应客户疑问、写痛点 | `03-客户需求库`（高频问题、客户原话） |
| 讲故事、晒案例 | `04-素材案例库`（客户故事、好评原话、踩坑经历） |
| 输出专业判断 | `05-方法论库`（你的行业认知、做事标准） |

没有知识库也能写（用户当场口述信息），但每次都提醒一句：「先花 30 分钟跑一遍知识库采访机器人，以后写得更快更像你。」

| 用户信号 | 走哪个流程 |
|---------|----------|

## 7 种风格速查（详见 `references/`）

| 风格 | 适用场景 |
|------|--------|
| A 高信息密度条目体 | 多条独立观点并列，线下交流／课程笔记／读书心得 |
| B 观点驳论体 | 反常识、纠偏、打脸主流观点 |
| C 故事案例体 | 客户对话、朋友咨询、具体事件 |
| D 碎碎念反思体 | 个人感悟、瞬间灵感 |
| E 方法论拆解体 | 系统化分享、解构误区、教学性内容 |
| F 类比观察体 | 生活观察、用具象讲抽象 |
| G 口语叙事体 | 个人经历分享、业务感悟、决策解释 |

完整映射表见 `references/README.md`。**写作前必须先读对应风格文件**获取该风格的 DNA 特征、示例和模板。

## 三道关口（输出框架时附带状态）

### 关口一：业务元素检查
这条文案里，能自然融入至少一项你的真东西吗？
- 你的产品／服务的真实使用场景
- 你的客户案例或客户原话
- 你的专业判断或行业观察
- 你的真实经历（含踩坑）

### 关口二：产品桥梁检查
读者看完，会不会产生「我也想要」「想找他问问」的念头？

| 桥梁强度 | 说明 |
|---------|------|
| 强桥梁 | 内容直接展示产品／服务能力 |
| 中桥梁 | 内容自然提到你在做的事 |
| 弱桥梁 | 文末一句话轻带 |
| 无桥梁 | 跟你的生意完全无关（偶尔可以，常态不行） |

### 关口三：辨识度测试
把这条文案的署名换成你的同行，还成立吗？
- 成立 → 缺少你的实战视角或个人判断，重写
- 不成立 → 有辨识度 ✅

**展示格式：**
```
【三道关口】业务元素：✅/⚠️ ｜ 产品桥梁：强/中/弱/⚠️无 ｜ 辨识度：✅/⚠️
```

## 情绪路径设计（写正文前必做）

**验证过的模式**：共鸣或冲击（开头抓注意）→ 转折＋论证（中间建信任）→ 观点或金句（结尾给收获）

| 象限 | 情绪 | 内容策略 |
|------|------|---------|
| 高唤醒＋积极 | 惊喜、兴奋 | 效果展示：真实结果、前后对比 |
| 高唤醒＋消极 | 焦虑、反常识冲击 | 痛点诊断：指出「你现在的方式有问题」 |
| 低唤醒＋积极 | 信任、安心 | 方法展示：给具体步骤和路径 |
| 低唤醒＋消极 | 无聊、倦怠 | **禁止区**：纯情绪共鸣、无干货无判断 |

写正文前用一句话定路径：`开头：[高唤醒+X] → 中间：[低唤醒+积极] → 结尾：[高唤醒+积极]`

## 通用规范（所有风格共享）

### 长度

| 类型 | 字数 | 适用 |
|------|------|------|
| 短文案 | 100-300 字 | 一个小观察、一句感悟＋案例 |
| 中文案 | 300-800 字 | 一个完整观点＋论证＋收尾（**默认**） |
| 长文案 | 800-1500 字 | 系统性分享、多点论证 |

### 语气

- **像朋友聊天**，不是教育读者；用「我」的视角叙述
- **极度直接**：不铺垫不绕弯，第一句话进正题
- **允许不完美**：可以说「我也不确定」「这个我还在摸索」
- **观点要笃定**：B／E 风格里不用「可能」「或许」「大概」

### 禁用词汇和表达

**官话腔（绝对禁止）**：「综上所述」「总而言之」「不难看出」「值得一提的是」「首先……其次……最后」「鉴于」「基于上述分析」

**互联网黑话（禁止）**：「赋能」「抓手」「闭环」「打法」「链路」「矩阵」「布局」

**AI 味表达（重点排查）**：「说个扎心的事实」「事情就完全不一样了」「信息太多，反而让你瘫痪了」——过度文学化的句子全删

**生造比喻（禁止）**：类比必须来自你的真实生活场景，AI 不许现编；宁可直说，不硬比喻

**情绪堆砌（禁止）**：「震惊」「绝了」「干货满满」「建议收藏」「轻松赚钱」「普通人也能」

### 格式

- 段落极短，经常一句话一段；**段与段之间空行**
- 编号用 1️⃣2️⃣3️⃣ 或「1、」，不用「1.」
- 引号用直角引号「」
- **中文标点强制**：全文用中文标点（，。：？！、；「」——……），禁止英文标点混入
- **一条文案只讲一件事**：一个案例＋一个观点＋一个情绪就够

### 内容

- **具体数字 > 形容词**（「3 天回了 27 个咨询」好过「咨询量暴涨」）
- **客户案例穿插但不暴露姓名**（「有个客户」「一个老顾客」）
- **自嘲自黑是信任加速器**（说踩坑、说走弯路，比说成绩更拉近距离）
- **观点 > 信息**：读者不缺知识，缺的是你的判断

## 5 个核心写作流程

### 流程 A：话题 → 多角度框架 → 选定写作

1. 用户给话题方向
2. 读 `references/README.md` 映射表，选 2-3 个候选风格
3. **输出 3 个框架**供选择，每个含：核心切入点、对应风格、示例开头（2-3 句）、结构（开场→正文→收尾）、三道关口状态、情绪路径
   - **老板本人视角**（固定主力）：用「我」叙述，必须有你知识库里的真实案例或数据
   - **专家视角 A＋B**（按话题匹配，说明选择理由）：从专家池选——Naval（特定知识）、Gary Halbert（饥饿人群）、Alex Hormozi（大胆断言）、李叫兽（认知冲突）、刘润（模型对比）、半佛仙人（反讽拆解）等
4. **等用户选定框架**（不许代选）
5. 读对应风格文件，按选定框架＋情绪路径写正文

### 流程 B：调知识库 → 整合观点 → 写文案

1. 按话题搜知识库：`05-方法论库`（你的判断）＋`04-素材案例库`（故事）＋`03-客户需求库`（客户原话）
2. 输出**观点提炼清单**＋推荐风格（多观点并列→A；反常识→B；一套方法→E），等用户确认取舍
3. 用户确认后，读风格文件写正文，附三道关口＋情绪路径

### 流程 C：粗糙想法 → 专家视角完善 → 写文案

1. 用户倒出想法（背景／观点／论据，不用完善）
2. AI 选一位最匹配的专家，输出：选谁、为什么（三句话）

| 话题方向 | 推荐专家 | 核心理论 |
|---------|---------|---------|
| 差异化／护城河 | Naval Ravikant | 特定知识、不可复制性 |
| 筛选客户／长期主义 | Gary Halbert | 饥饿人群、筛选式文案 |
| 观点输出／短句冲击 | Alex Hormozi | 大胆断言、打断模式 |
| 营销策略／消费者洞察 | 李叫兽 | Y 型文案、认知冲突 |
| 商业分析／反割韭菜 | 半佛仙人 | 接地气的商业拆解 |
| 商业模型／对比分析 | 刘润 | 模型思维 |
| 人性／行为动机 | 罗伯特·萨波斯基 | 行为学、多层归因 |

3. 用专家逻辑补全观点闭环，匹配风格（成体系→E；反常识→B；类比→F；多点→A），附三道关口
4. 读风格文件写正文——**观点用专家的逻辑，语言用你的风格**

### 流程 D：具体事件 → 提炼观点 → 写文案

1. 用户描述事件／客户对话／观察
2. AI 提炼 2-3 个观点方向＋自动匹配风格（对话→C；生活观察→F；反常识→B；完整方法→E），等用户选
3. 读风格文件写正文
4. 写完检查逻辑闭环：事件和观点的关联自然吗？有没有「然后呢」？结尾有力吗？

### 流程 E：录音转写稿 → 萃取 → 勾选 → 写文案

> 输入：转写稿文本（粘贴）或文件路径。装了「录音处理」skill 的，重度整理走它，本流程只负责「录音→朋友圈」这一件事。

1. **拿到转写稿**（用户粘贴或给路径；已有整理稿直接用整理稿）
2. **按长度分流**：
   - < 3000 字 → 直接读全文写正文
   - 3000-10000 字 → 先萃取 10-15 条信息点，用户勾选后写
   - > 10000 字 → 萃取并分类（核心观点／金句原话／案例数据），用户勾选后写
3. **萃取格式**：
   ```
   【核心观点】（5-8 条，一句话一条）
   【金句／原话】（3-5 条，照抄）
   【具体案例／数据】（2-4 条）
   ```
4. **等用户勾选**要写哪些、怎么排序
5. 按录音类型推荐风格（交流会→A；对话咨询→C；个人碎碎念→D；系统分享→E），读风格文件写正文

## 2 个延伸动作

### 延伸 1：朋友圈文案 → 口播逐字稿
- 开头黄金 3 秒：痛点问句→短句否定→归因转移→展开
- 句子拆短，一句一口气；删掉「我问她、她说」对话形式，直接讲
- 预估时长 60-80 秒

### 延伸 2：生成小红书标题
10 种技巧：痛点＋否定／人群＋结果／反常识／数字＋具体行为／金句前置／疑问＋答案／劝诫式／对比式／身份＋观点／挑战认知

## 合规红线

- ❌ 不写具体收入数字（可写「回了很多咨询」，不写「赚了 X 万」）
- ❌ 不写「普通人轻松赚钱」类暗示；不承诺效果
- ❌ 客户案例必须脱敏：不写姓名、不写具体金额
- ✅ 可以写：方法论和认知输出、自己的真实经历和思考、行业观察

## 质量自检清单（写完逐项过）

- [ ] 风格匹配所选风格的 DNA 特征
- [ ] 一句话能说清核心观点
- [ ] 逻辑闭环：开头到结尾有完整因果链
- [ ] 不止抛问题，给了方向或行动
- [ ] 只讲一件事，不贪多
- [ ] 是用户的语气：直白、口语化、短句
- [ ] 有真实案例或数据支撑，不是空洞道理
- [ ] 三道关口通过（业务元素／产品桥梁／辨识度）
- [ ] 情绪路径不全程低唤醒
- [ ] 合规：没碰红线
- [ ] 段落够短、段间有空行
- [ ] 结尾有力：金句／反问／行动指引，不烂尾
- [ ] 中文标点全部正确
