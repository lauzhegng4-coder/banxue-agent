# feishu-companion-agent

把一堆资料库变成「会教的 AI 伴学智能体」的完整方法论。

## 解决什么问题

你有一堆学习资料——课程讲义、群聊精华、逐字稿——学员消化不过来、水平参差不齐。这个 skill 教你把它变成一个 **懂学员、会教人、能持续喂养** 的 AI 伴学智能体，跑在飞书私聊里。

## 核心内容（四层资产）

| 层 | 内容 | 决定什么 |
|---|---|---|
| ① 知识库 | KNOWLEDGE.md 总索引 + K 号编号原文 + 框架摘要 | Agent 知道什么 |
| ② 伴学 SOP | 定档→路线图→陪跑→复盘；「结论→依据→落地动作」三段式回答 | Agent 怎么教 |
| ③ 学员画像 | 一人一档，首次建档 + 每次对话更新 | 对谁因材施教 |
| ④ 喂养通道 | 飞书 API 全文抓取等方法持续入库 | 会不会过时 |

通道（Hermes + 飞书自建应用 + 长连接 + 配对审批）只是落地手段，SKILL.md 里简述。

## 适用场景

- 付费社群/训练营知识库伴学 bot
- 企业培训资料答疑助手
- 个人「第二大脑」问答
- 任何「资料多、学员水平参差、需要因材施教」的场景

## 学员首次对话（开场引导）

Agent 第一次被私聊时，用这段开场快速定位学员兴趣，不先抛建档三连问：

> 我是航海家伴学 Agent。
> 航海家（生财有术高阶会员社区）课程里几位讲师各管一块，你随便挑，我用最不绕弯、最直白的方式讲给你听：
> - 叁斤：知识库→内容 Agent（把资料变成会干活的 AI）、课前准备与学习路径
> - 楚川：AI 内容工程化、IP 访谈（挖出一个 IP 的内容）、项目与竞品信息收集
> - 包子：成为 AI 的伯乐（识别、驾驭 AI 能力，选对工具）
> 你对哪一块最感兴趣？说讲师名或话题都行，我直接开讲。

学员选完兴趣点，Agent 再顺带补全个人建档（水平/目标/时间），进入定档→路线图→陪跑→复盘。

## 使用

SKILL.md 为 WorkBuddy/Hermes 通用 skill 格式，放入 `~/.workbuddy/skills/` 即可被识别。

## 实测背景

基于航海家俱乐部（生财有术）伴学 Agent 的完整搭建验证：9 份课程资料入库、四阶段 SOP、飞书私聊全链路（配对/答疑/画像更新）跑通。
